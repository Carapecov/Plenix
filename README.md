# Plenix

**Uma plataforma digital voltada ao desenvolvimento e crescimento de microempreendedores locais.**

O Plenix é um projeto desenvolvido pela minha equipe com o propósito de apoiar microempreendedores na organização de seus negócios e na identificação de oportunidades de crescimento, alinhando-se à **ODS 8 — Trabalho Decente e Crescimento Econômico**, da Organização das Nações Unidas.

O projeto combina desenvolvimento de software e visão de produto para explorar como soluções digitais podem contribuir para os desafios enfrentados por pequenos empreendedores.

## Objetivo do projeto

Desenvolver uma solução digital que auxilie microempreendedores locais a compreender melhor seus negócios e encontrar oportunidades para sua evolução.

Além do propósito do produto, o projeto envolve a aplicação prática de conceitos de desenvolvimento de software, organização de código e estruturação de uma solução orientada a um problema real.

## Problema e proposta de valor

Pequenos empreendedores enfrentam desafios relacionados à organização, parte financeira, legislação e outros.

O Plenix busca contribuir para esse cenário por meio de uma plataforma digital direcionada a esse público. Agregando dicas que podem solucionar diferentes casos, dependendo do perfil do MEI.

**Proposta de valor:** aproximar recursos e orientações úteis da realidade de microempreendedores, considerando suas necessidades e possibilidades de crescimento.

## Funcionalidades

* Formulário de identificação de perfil
* Gerar a melhor dica com base no formulário
* Visualização de todas as dicas

## Tecnologias utilizadas

| Tecnologia                     | Aplicação no projeto |
| ------------------------------ | -------------------- |
| PHP                            | É utilizada como linguagem principal, atua na lógica de todo o sistema, no formulário, na dica gerada e outros. Usamos PHP por ser bem prática para desenvolvimento Web e exclusivamente, na parte de formulários.   |
| Arquitetura MVC                | Organização do projeto, permite reutilizar funcionalidades de outros arquivos, separação de responsabilidades, testes mais eficientes e melhor para a organização da equipe   |
| SQL(MySQL)                     | Dicas e situações    |
